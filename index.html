WEEKLY ACTIVITY

My Responsive Gallery

Create a responsive webpage that displays your favorite things using CSS Grid and a responsive YouTube video.

ACTIVITY INSTRUCTIONS

Objective

Create your own responsive gallery webpage using HTML and CSS. Your webpage should automatically adjust its layout when the screen size changes.

What You Need to Do

  1. Create an HTML file named index.html.
  2. Create a CSS file named W2STYLE.css.
  3. Choose 3 to 6 things that you like or are interested in.
  4. Add an image for each item.
  5. Add a title and short description for every image.
  6. Arrange your items using CSS Grid.
  7. Use a responsive layout that changes when the screen becomes smaller.
  8. Add one YouTube video related to your topic.
  9. Make the YouTube video responsive.
  10. Test your webpage using different screen sizes.

Required CSS Grid Features

  • Use display: grid;
  • Use grid-template-columns
  • Use gap to create space between your cards
  • Use a media query to change the number of columns
  • Make your images responsive

Required Responsive Features

  • Your gallery should display multiple columns on a large screen.
  • Your gallery should have fewer columns on a smaller screen.
  • Your webpage should remain readable on a mobile-sized screen.
  • Your video should automatically adjust to the screen width.

Important Reminders

  • Do not copy another student's topic, design, or content.
  • You may use online images that are appropriate for school use.
  • Use meaningful alt text for your images.
  • Check that all images are displayed correctly.
  • Check your webpage on both a large and small screen.
  • Make sure your HTML and CSS files are saved in the correct folder.
